# 🛰️ ARES-NAV 2.0 // Autonomous Martian EVA & ISRU Digital Twin OS
**Team ShunnyaVerse — NASA Space Apps Challenge 2026**

### 🌍 Overview
**ARES-NAV 2.0** is a physics-informed geospatial digital twin operating system for **Jezero Crater (18.45°N, 77.41°E)**. It integrates NASA orbital and Perseverance rover telemetry to compute multi-objective EVA routes, dynamic ray-cast xEMU AR helmet visor overlays, and Pandolf-Santee metabolic life-support budgets.

### 🛰️ Official NASA Datasets Used
* **NASA Mars Trek & MGS MOLA / HiRISE DEM:** (`PDS ID: MEG128_004`, `ESP_068295_1985`, `ESP_078420_1985`) — https://trek.nasa.gov/mars/
* **Mars 2020 Perseverance Waypoints & MEDA Weather Logs:** Sol 0 to Sol 1122 live telemetry — https://mars.nasa.gov/mars2020/weather/
* **MRO SHARAD Subsurface Radar & CRISM Spectrometer:** (`PDS ID: R_1289401`, `FRT000047A3`) — https://pds-geosciences.wustl.edu/missions/mro/
* **MSL Curiosity RAD & MAVEN SEP Dosimetry:** Autonomous Lava Tube abort routing during solar particle events.
